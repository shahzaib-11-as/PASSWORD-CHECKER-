# Password Security Checker — CMD System

A professional **Python-based Command-Line Password Security Checker** designed to evaluate password strength and provide actionable security recommendations.

The system analyzes passwords based on multiple security factors, including **password length, character variety, common-password detection, repeated characters, sequential patterns, and predictable patterns**. It generates a security score and categorizes the password as **Low, Medium, or High Risk**.

## Key Features

* Secure password input using hidden terminal entry
* Password length analysis
* Uppercase, lowercase, number, and special-character detection
* Common-password detection using a password dataset
* Detection of repeated characters
* Detection of sequential letters and numbers
* Predictability analysis
* Security score calculation
* Low / Medium / High risk classification
* Actionable recommendations for improving weak passwords
* Professional CMD interface with colored output
* Simple and beginner-friendly Python implementation
